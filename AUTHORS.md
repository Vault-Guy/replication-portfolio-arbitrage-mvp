# Authors and research contribution

This repository implements a research project developed jointly by:

- **Mikhail Chekunov** — [@mikhailchekunov](https://github.com/mikhailchekunov)
- **Nikita Lukianenko** — [@Vault-Guy](https://github.com/Vault-Guy)

## Joint research contribution

The joint work behind the project included:

- development of the PCA-based synthetic replication framework for a target asset, including log-price representation, PCA factors, regression-based reconstruction and walk-forward out-of-sample evaluation;
- design of the statistical-arbitrage strategy based on the spread between the target asset and its synthetic replication, causal rolling z-scores, entry/exit thresholds, delayed execution and transaction costs;
- design of experiments across U.S. equities, Russian equities and crypto assets, including rolling training windows, rebalancing frequencies and parameter grids;
- analysis of strategy robustness and replication quality using return, Sharpe ratio, drawdown, turnover, trade statistics, target-level comparisons and parameter-stability diagnostics;
- interpretation and presentation of the empirical results.

The repository is an implementation of this jointly developed research project. Where the Git history identifies individual implementation work, it should be used to attribute specific code changes.
