# Grid Search Results — Справочник

## Быстрая навигация: куда смотреть в первую очередь

| Вопрос                                                | Файл |
|-------------------------------------------------------|------|
| Какие параметры лучшие по каждому рынку?              | `summary_by_market.csv` |
| Какие параметры лучшие для конкретного актива?        | `summary_by_target.csv` |
| Какие параметры работают стабильно на многих активах? | `top_robust_params.csv` |
| Полные данные для своего анализа                      | `grid_search_results.csv` |
| Что упало во время прогона                            | `grid_search_failures.csv` |

## Файлы

### `grid_search_results.csv` — сырые результаты (1440 строк)

Одна строка = один прогон: рынок × актив × rebalance_frequency × (entry_z, exit_z).
Всего: 3 рынка × 5 активов × 4 частоты × 24 пары z-порогов = 1440 запусков.

**Параметры прогона:**

| Столбец | Что это |
|---------|---------|
| `market` | Рынок: `usa`, `russia`, `crypto` |
| `target` | Актив, который торгуем (AAPL, BTC, AFKS и т.д.) |
| `train_window` | Окно обучения в барах: 252 (дни) для акций, 1440 (часы) для крипто |
| `rebalance_frequency` | Как часто пересчитываем позицию: 5/10/21/63 дней для акций, 24/72/168/336 часов для крипто |
| `entry_z` | Z-score для входа в позицию (1.0 / 1.5 / 2.0 / 2.5 / 3.0) — чем выше, тем реже входим |
| `exit_z` | Z-score для выхода из позиции (0.0 / 0.25 / 0.5 / 0.75 / 1.0) — всегда < entry_z |
| `pca_explained_variance` | Сколько дисперсии объясняет PCA (фиксировано 0.8) |
| `zscore_lookback` | Окно для расчёта z-score: 60 дней (акции), 336 часов (крипто) |
| `transaction_cost_bps` | Комиссия: 5 bps для USA, 10 bps для Russia и Crypto |
| `annualization_factor` | Для пересчёта в годовые: 252 (акции), 8760 (крипто, часов в году) |

**Вселенная активов:**

| Столбец | Что это |
|---------|---------|
| `universe_selection_method` | Метод отбора: `priority` (приоритетный список) или `coverage` (по покрытию данных) |
| `universe_size_requested` | Запрошено активов в вселенную (30) |
| `universe_size_actual` | Реально взято (может быть меньше, если данных не хватает) |
| `universe_assets` | Список активов вселенной через запятую |
| `missing_priority_assets` | Активы из приоритетного списка, которые не нашлись в данных |
| `filled_from_fallback` | Активы, добавленные вместо отсутствующих (из fallback-списка) |

**Метрики бэктеста — ключевые:**

| Столбец | Что это | На что смотреть |
|---------|---------|-----------------|
| `sharpe_ratio` | Главная метрика: годовой доход / годовая волатильность | > 1.0 — хорошо, > 1.5 — отлично |
| `total_return` | Совокупный доход за весь период (1.5 = +50%) | В крипто может быть 50–500× из-за длинного периода |
| `annualized_return` | Годовой доход (геометрический) | — |
| `annualized_volatility` | Годовое стандартное отклонение доходностей | — |
| `max_drawdown` | Максимальная просадка от пика (отрицательное число) | Ближе к 0 — лучше; -0.5 и хуже — тревожный сигнал |
| `hit_rate` | Доля прибыльных сделок | > 0.5 — стратегия угадывает направление чаще чем нет |

**Метрики бэктеста — дополнительные:**

| Столбец | Что это |
|---------|---------|
| `turnover` | Средний оборот портфеля за период (доля позиций, сменившихся) |
| `number_of_trades` | Общее количество сделок за всю историю |
| `average_holding_period` | Средняя длительность удержания позиции (в барах) |

### `summary_by_market.csv` — сводка по рынку (3 строки на рынок × 2 метрики = 6 строк)

Содержит **лучший прогон** по каждому рынку (отдельно по Sharpe и по total_return) плюс агрегаты по всему рынку.

Все столбцы из `grid_search_results.csv` плюс:

| Столбец | Что это |
|---------|---------|
| `selection_metric` | По какой метрике выбрана эта строка: `sharpe_ratio` или `total_return` |
| `selection_value` | Значение этой метрики |
| `flag_few_trades` | Мало сделок (< 10) — Sharpe ненадёжен |
| `flag_high_turnover` | Очень высокий оборот (выше 95-го перцентиля) — возможны скрытые издержки |
| `flag_large_drawdown` | Просадка глубже −50% — риск велик |
| `flag_cost_fragile` | Стратегия чувствительна к росту комиссий |
| `suspicion_flags` | Текстовое перечисление сработавших флагов |
| `runs` | Сколько прогонов было по этому рынку (480) |
| `target_count` | Сколько активов в рынке (5) |
| `median_sharpe` | Медианный Sharpe по всем 480 прогонам рынка — **главный показатель стабильности** |
| `median_total_return` | Медианный total_return по всем прогонам |
| `median_max_drawdown` | Медианная просадка |
| `median_turnover` | Медианный оборот |
| `median_trades` | Медианное число сделок |
| `positive_sharpe_share` | Доля прогонов с Sharpe > 0 — **показатель надёжности рынка** |
| `positive_return_share` | Доля прогонов с положительным доходом |
| `transaction_cost_bps_market` | Комиссия для этого рынка |

> **Самые важные столбцы здесь:** `median_sharpe`, `positive_sharpe_share`, `sharpe_ratio` лучшего прогона, `flag_*`.

### `summary_by_target.csv` — сводка по активу (15 строк × 2 метрики = 30 строк)

Аналогично `summary_by_market.csv`, но детализация до каждого актива.

Дополнительные столбцы (которых нет в summary_by_market):

| Столбец | Что это |
|---------|---------|
| `best_sharpe` | Лучший Sharpe среди всех 96 прогонов этого актива |
| `best_total_return` | Лучший total_return среди всех прогонов |

> **Смотреть:** `median_sharpe` — насколько актив хорошо торгуется в среднем независимо от параметров. Высокий `best_sharpe` при низком `median_sharpe` = один удачный параметр, а не стабильная стратегия.

### `top_robust_params.csv` — устойчивые параметры (~100 строк)

Показывает, какие **комбинации параметров** (rebalance + entry_z + exit_z) стабильно попадают в топ-10% по Sharpe у **разных активов**.

| Столбец | Что это |
|---------|---------|
| `market` | Рынок |
| `rebalance_frequency` | Частота ребалансировки |
| `entry_z` | Порог входа |
| `exit_z` | Порог выхода |
| `top_decile_appearances` | Сколько раз эта комбинация попала в топ-10% у разных активов |
| `targets_represented` | У скольких **разных** активов эта комбинация в топ-10% |
| `median_sharpe_in_decile` | Медианный Sharpe этой комбинации среди попаданий в топ-10% |
| `median_total_return_in_decile` | Медианный return при попаданиях в топ-10% |
| `top_decile_slots` | Всего слотов в топ-10% (50 при 500 прогонах) |
| `appearance_rate` | Доля слотов, занятых этой комбинацией (top_decile_appearances / top_decile_slots) |

> **Самые важные столбцы здесь:** `targets_represented` (чем больше, тем робастнее) и `median_sharpe_in_decile`. Комбинация с `targets_represented = 4–5` значит, что она работала хорошо почти на всех активах рынка — это не случайность.

## Ключевые моменты

### Как читать Sharpe
- `sharpe_ratio` в `best_by_market` — **лучший из 480 прогонов**. Это оптимистичная оценка.
- `median_sharpe` в `summary_by_market` — **типичный результат**. Вот реальная картина.
- Разрыв между ними большой? Значит, стратегия зависит от точного подбора параметров.

### Флаги подозрительности
Если в топе строки с `flag_large_drawdown = True` или `flag_few_trades = True` — Sharpe там ненадёжен. Большой Sharpe при 5 сделках за 5 лет — статистический шум.

### Crypto vs акции
В крипто `total_return` выглядит огромным (50–500×), потому что история длиннее (~5 лет × 8760 часов). Для сравнения рынков смотри именно `sharpe_ratio` и `annualized_return`.

### Что значит robust
Комбинация параметров робастна, если она в топ-10% у 4–5 разных активов (`targets_represented` в `top_robust_params.csv`). Одиночное попадание у одного актива — скорее всего, переподгонка.
